Options

Downloads you mark as temporary are kept in a folder of their own, and deleted every time your browser starts.

“Ask where to save each file before downloading” in your browser’s download settings need to be turned off for this extension to work correctly.

Temporary Folder:

This folder is created inside your browser’s download directory. If you change this download directory later in your browser’s settings, the old temp folder will be orphaned. This extension will no longer be able to find it or clear it, and its contents stay on disk until you delete them yourself.
